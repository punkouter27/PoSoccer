Learning curves

Smoothed. Each agent's steps run along its own lineage: a round's curve starts where the run it continued from ended.

Reward per match

The score the agent earns in a training match. It rises as the agent learns what the reward table pays for. It does not decide anything here (CLAUDE.md): the graded matches below do.

Stalemate rate in training

The share of training matches that ran out the clock with no goal. The benchmark allows at most 10% in grading, and this is the criterion MATT and NICK failed after p38.

Match length (decision steps)

How long a match lasts. Shorter means goals come sooner, whichever side scores them.

Value loss

How wrong the agent's own prediction of its future reward was. It spikes when the opponent or the curriculum changes and settles as the agent re-learns to predict.

Policy loss

The size of each update to the agent's decision rule. PPO keeps it small on purpose; a flat, small line means steady learning rather than lurches.

Exploration (entropy)

How random the agent's actions still are. It falls as the agent commits to what works.

Opponent strength

The curriculum: how strong the scripted bot was (1.0 = the full-strength bot used for grading).

Reading the numbers

  • 350 graded matches pin a win rate to about ±2 points; the final grade uses 1000 matches (about ±1.3).
  • Training reward and grades can disagree. This project has seen a rising curve end in a worse grade three times, so only the grades decide what ships.
  • Production weights live in Assets/Agents/<Name>_v01/<NAME>.onnx; every round's checkpoints stay in results/<run>/.
