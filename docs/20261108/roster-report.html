Reward per match

Up is better. It measures how much the agent earns per training match. Useful to see learning happen; the graded matches decide what ships.

Stalemate rate in training

Down is better. Share of matches that time out with no goal; the bar allows 10%.

Match length (decision steps)

Usually down is better: matches end sooner because someone scores.

Value loss

The agent's error predicting its own future score. Spikes when the opponent gets harder, then settles.

Policy loss

Size of each learning step. Small and steady is healthy.

Exploration (entropy)

How much the agent still experiments. Falls as it commits to what works.

Opponent strength

How strong the practice opponent is. The curriculum raises it as the agent improves; grading uses full strength.
